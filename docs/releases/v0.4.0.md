# GaugeMesh 0.4.0 — Bounded durable Runs developer preview

This release adds immutable caller-authored Run plans over the existing durable
Tasks. GaugeMesh remains a local-first capability and model router. It does not
become a planner, scheduler, domain solver, or new database product.

## Included behavior

- Complete bounded-plan admission, caller-scoped idempotency, stable per-step
  Task identity, and atomic Run state/journal transitions in the existing SQLite
  database.
- Explicit resume/status/cancel/export/verify operations, required artifact
  validation before successors, cancellation accounting, and no automatic replay
  of ambiguous effects.
- Descriptor-relative no-symlink artifact verification, exact execution/input/
  policy/attempt bindings, and `gaugemesh run-verify --evidence export.json` for
  offline verification without any executable validator.
- Reserved-local-identity refusal for remote OIDC tokens, current effect-scope
  rechecks, and read-only retained Task recovery after an execution deadline.
- Independent Python and JavaScript callers/workers, live acknowledgement loss,
  actual gateway restart/kill, bounded concurrency, artifact corruption refusal,
  and fresh public-binary qualification in the release gate.

See [the public contract](../durable-runs.md) and its exact installed-binary
commands. External scripts live in `examples/public_tasks` at this source tag;
they need Python or Node, not Rust. Native archives retain the existing compact
package layout. The release workflow downloads the actual public archive,
checks its digest and attestation, runs both independent consumers, and retains
their raw evidence as `public-install-verification`.

## Limits and compatibility

Runs are opt-in, local-caller, Unix artifact workflows with a maximum of 16 steps,
four concurrent Tasks, and one attempt per step. Remote Runs and Windows artifact
execution are explicitly refused. SQLite schema version 3 adds Run tables;
back up your own database before upgrade. Older binaries cannot open the upgraded
schema. Existing MCP 2025-11-25 and ordinary routing behavior remain supported;
that older protocol does not advertise Tasks or Runs.

Cancellation acknowledgement is not worker termination. Deadline enforcement
requires resume/poll activity. In-flight outcomes remain accounted for after
fail-fast. A changed provider session can leave reconciliation-required state,
never guessed success or an extra side effect. Integrity hashes are unsigned;
retain a trusted original export. Workers must implement their declared bounds
and exclusive writes; GaugeMesh does not sandbox arbitrary hostile workers.

The historical ResiliReplay 0.7.0 matrix remains **PARTIAL: 3 PASS, 10 FAIL, 13
rows**. Its recorded-trace mutations are not live-wire fault injection and are
not replaced by the separate external tests. No benchmark, production-readiness,
exactly-once, domain-compliance, or certification claim is made.

GitHub Releases and the public GHCR image remain the supported distribution
channels. Both Rust crates retain `publish = false`. No crates.io publication is
part of this release.
